# HeTec Provisionsabrechnung

PWA für die monatliche Provisionsabrechnung (o2).

1. Performance-Excel ablegen
2. Telefonie-Excel (WOBIS) ablegen
3. Prüfen, Sonderprovision / Shopleiter / Gutschriften eintragen
4. „Provision generieren“ (ZIP) oder „Provisionen per E-Mail senden“ (Outlook-Entwurf)

Alle Daten bleiben lokal im Browser (localStorage). Keine Daten werden hochgeladen.
